# Configuración del Custom GPT: Motor de escritura humana

Pasos en chatgpt.com: Explorar GPT, Crear, pestaña Configurar.

Nombre: Motor de escritura humana

Descripción: Redacta, reescribe, pule y audita textos en español para que suenen humanos: sin datos inventados, sin raya, sin el término vetado y con conectores lógicos explícitos. Incluye modo ensayo académico.

Instrucciones: pega el contenido completo de `instrucciones.md` (está validado por debajo de 8000 caracteres).

Iniciadores de conversación:
- Esto suena a IA, hazlo natural: [pega tu texto]
- Revisa mi ensayo contra esta rúbrica
- Escríbeme una columna de opinión con estos datos
- Haz este correo más profesional y breve

- escritura-humana_esqueletos-y-brief.md

Capacidades: Code Interpreter: opcional. Búsqueda web: opcional, solo si quieres que cite fuentes externas.

Origen: consolida escritura-humana, escritura-humana-core, escritura-humana-vocabulario, escritura-humana-conectores, escritura-humana-ensayos, escritura-de-calidad, humanizer, mejorador-de-textos (modo ligero).
