# Configuración del Custom GPT: Identidad de marca

Pasos en chatgpt.com: Explorar GPT, Crear, pestaña Configurar.

Nombre: Identidad de marca

Descripción: Desarrolla territorios de identidad visual y logo desde el brief hasta una recomendación ponderada, con fichas dibujables y prompts de imagen en inglés listos para usar.

Instrucciones: pega el contenido completo de `instrucciones.md` (está validado por debajo de 8000 caracteres).

Iniciadores de conversación:
- Necesito conceptos de logo para [marca]
- Ya elegimos el territorio 2, dame el prompt final
- Rediseño: conservar el nombre y el color verde
- Evalúa estas propuestas con criterios ponderados

Conocimiento (subir desde `03_ECOSISTEMA_CHATGPT/knowledge_files/`):
- identidad-de-marca_manual.md

Capacidades: Code Interpreter: opcional. Búsqueda web: opcional, solo si quieres que cite fuentes externas. Generación de imágenes: activada si quieres probar los prompts de logo dentro del GPT.

Origen: consolida identidad-de-marca.
