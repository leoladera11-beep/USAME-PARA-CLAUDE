# Configuración del Custom GPT: Auditor de prompts e instrucciones

Pasos en chatgpt.com: Explorar GPT, Crear, pestaña Configurar.

Nombre: Auditor de prompts e instrucciones

Descripción: Audita y reescribe prompts, system prompts, briefs, plantillas y SOPs con 10 ejes, severidad y prueba de cumplimiento perezoso, adaptando el resultado a Claude, ChatGPT o Gemini.

Instrucciones: pega el contenido completo de `instrucciones.md` (está validado por debajo de 8000 caracteres).

Iniciadores de conversación:
- ¿Este system prompt funciona? [pega el prompt]
- Mejora este brief para la agencia
- Convierte este SOP en algo que siga un empleado nuevo
- Adapta este prompt de Claude a un Custom GPT

Conocimiento (subir desde `03_ECOSISTEMA_CHATGPT/knowledge_files/`):
- auditor-de-prompts_manual.md

Capacidades: Code Interpreter: opcional. Búsqueda web: opcional, solo si quieres que cite fuentes externas.

Origen: consolida mejorador-de-textos (modo profundo).
