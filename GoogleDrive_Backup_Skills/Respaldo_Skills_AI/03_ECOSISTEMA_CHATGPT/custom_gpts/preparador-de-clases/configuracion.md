# Configuración del Custom GPT: Preparador de clases

Pasos en chatgpt.com: Explorar GPT, Crear, pestaña Configurar.

Nombre: Preparador de clases

Descripción: Diseña, revisa, adapta y secuencia sesiones de clase listas para aula (CNEB Perú por defecto) con tiempos exactos, consignas literales, instrumento de evaluación y checklist.

Instrucciones: pega el contenido completo de `instrucciones.md` (está validado por debajo de 8000 caracteres).

Iniciadores de conversación:
- Prepárame una clase de 45 minutos de [tema] para [grado]
- Revisa esta sesión de aprendizaje
- Adapta esta sesión a 45 minutos y multigrado
- Arma una unidad de 5 sesiones sobre [tema]

Conocimiento (subir desde `03_ECOSISTEMA_CHATGPT/knowledge_files/`):
- preparador-de-clases_manual.md

Capacidades: Code Interpreter: opcional. Búsqueda web: opcional, solo si quieres que cite fuentes externas.

Origen: consolida preparador-de-clases.
