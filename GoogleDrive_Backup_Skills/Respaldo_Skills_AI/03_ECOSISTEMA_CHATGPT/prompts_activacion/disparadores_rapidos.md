# Disparadores rápidos

Frases y prompts listos para copiar en un Project de ChatGPT que tenga `SISTEMA_MAESTRO_CHATGPT.md` en las instrucciones y los archivos de `skills/` subidos. Las frases activan la skill por sí solas; los prompts reemplazan lo que está entre corchetes. Para forzar una skill concreta, nombra su archivo: "Usa la skill `<archivo>` para: ...".

## Motor de escritura humana (`escritura_humana_master.md`)

Frases que la activan: «suena a IA», «hazlo más natural», «humaniza este texto», «redacta», «reescribe», «corrige este texto», «pule», «mejora este correo», «escribe un ensayo», «revisa mi ensayo contra la rúbrica», «resume sin perder las citas».

Prompts listos para copiar:

- `Esto suena a IA, hazlo natural: [pega tu texto]`
- `Revisa mi ensayo contra esta rúbrica`
- `Escríbeme una columna de opinión con estos datos`
- `Haz este correo más profesional y breve`
- `Usa la skill escritura_humana_master.md para: [tu pedido]`

## Motor pedagógico (`tutor_aprendizaje_integral.md`)

Frases que la activan: «explícame», «quiero entender», «enséñame», «tengo examen», «hazme preguntas», «plan de estudio», «quiero aprender en tres meses», «audita este prompt de tutoría».

Prompts listos para copiar:

- `Explícame [tema] con preguntas, no con la respuesta`
- `Tengo examen de [tema] el viernes`
- `Quiero aprender [habilidad] en [plazo] con [horas] por semana`
- `Audita este prompt de estudio`
- `Usa la skill tutor_aprendizaje_integral.md para: [tu pedido]`

## Auditor de prompts e instrucciones (`auditor_prompts.md`)

Frases que la activan: «¿este prompt funciona?», «audita este prompt», «mejora este brief», «revisa este system prompt», «las respuestas salen genéricas», «convierte esto en un SOP».

Prompts listos para copiar:

- `¿Este system prompt funciona? [pega el prompt]`
- `Mejora este brief para la agencia`
- `Convierte este SOP en algo que siga un empleado nuevo`
- `Adapta este prompt de Claude a una skill de ChatGPT`
- `Usa la skill auditor_prompts.md para: [tu pedido]`

## Preparador de clases (`preparador_clases.md`)

Frases que la activan: «prepárame una clase», «sesión de aprendizaje», «planifica una sesión», «adapta esta sesión», «revisa mi sesión», «secuencia de sesiones», «unidad didáctica», «CNEB».

- `Usa la skill preparador_clases.md para: [tu pedido]`
